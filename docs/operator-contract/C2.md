# C2 — 通过 portable operator adapter 启动新 run

**结论：C2 通过。** 新的 1 peer × 1 generation run 完全由 `operator/praxist_operator.py` 启动、查询、收集，不再使用手写 shell 脚本。

## 任务

- task project：`praxist_bo_c2`
- 1 peer，1 generation
- 黑箱实验设计，6 个函数 × 3 seeds × 60 次评估
- task.yaml 已去掉 `/tmp`、`/home` 等绝对路径
- evaluator 仍在 `workspace` 外

## 命令链

```bash
python operator/praxist_operator.py --operator hermes --operator-version 1.0 \
  validate /home/andyl/PraxistExamples/praxist_bo_c2

python operator/praxist_operator.py --operator hermes --operator-version 1.0 \
  run /home/andyl/PraxistExamples/praxist_bo_c2 --config operator_config.json

python operator/praxist_operator.py --operator hermes --operator-version 1.0 \
  status run_c2_1 --task-project /home/andyl/PraxistExamples/praxist_bo_c2

python operator/praxist_operator.py --operator hermes --operator-version 1.0 \
  collect run_c2_1 --task-project /home/andyl/PraxistExamples/praxist_bo_c2 \
  --out evidence/
```

## 证明范围

这证明了：

- task project 可以不含绝对路径；
- adapter 可以 `validate → run → status → collect` 全链路；
- run 的成功/失败、generation、best metric 和证据 manifest 都可以机器读取；
- 同一个 run 用两个 operator 身份 collect，证据内容一致。

这还没有证明：

- C3：另一个**真正不同的前端 Agent** 能独立完成同样流程；
- C4：完整 RSI（多模块 candidate、held-out、promotion evidence）。
